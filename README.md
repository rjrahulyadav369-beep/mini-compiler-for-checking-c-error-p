# Mini Compiler Dashboard

This project is a Python-based web dashboard for a mini compiler design assignment. It follows the provided design brief and presents the project specification in a clean, document-inspired UI.

## Features
- Clean project dashboard matching the academic design reference
- Python implementation with Streamlit
- Lexical and syntax analysis simulation for sample C code
- Responsive layout for desktop and tablet views

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

You can deploy this app on:
- Streamlit Community Cloud
- Render
- Railway
- Hugging Face Spaces

Connect the GitHub repository and deploy the app from the platform settings page.

## Project summary
The application is designed around a mini compiler dashboard that analyzes C source code, identifies tokens, and detects lexical or syntax issues with a clear, user-friendly interface.
